## Skill Gap Analysis
**Description:** Identifies structured skill gaps based on user's current skills and career aspirations.


### Methodology
**Critical Gaps:** Mandatory technical or core skills the user has no experience in. Requires formal learning.

**Bridgeable Gaps:** Skills where the user has adjacent experience (e.g., knows Java, needs Python).

**Soft Skill Gaps:** Behavioral or leadership traits requiring development through coaching or experience.


## Career Transition Paths
**Description:** Dynamic rules for transitioning between archetypes and career paths.


### Transition Heuristics
**Step 1:** Identify the primary Role Type (IC, Manager, Strategist, Creator) of the target archetype.

**Step 2:** Identify the missing Tier 1 and Tier 2 traits required for the target career path by checking the career_to_trait_reverse_index.

#### Avoid Environments

## Validation Rules

### User Confirmation
**Description:** How to validate career recommendations with the user


#### Rules
- Ask: 'Do any of these career paths resonate with you?'
- If user agrees: 'Which one feels most aligned?'
- If user disagrees: 'What would you add or change?'
- If user is unsure: 'What appeals to you about each option?'

### Skill Gap Confirmation
**Description:** How to validate skill gaps with the user


#### Rules
- Ask: 'Do these skill gaps feel accurate?'
- If user agrees: 'Which skill would you like to develop first?'
- If user disagrees: 'What skills do you feel are missing?'
